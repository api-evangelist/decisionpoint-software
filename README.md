# DecisionPoint Software

DecisionPoint Software was a San Mateo, California-based enterprise software company that provided packaged financial performance management (FPM) and financial data warehousing software, built primarily around the Oracle ERP stack. Its systems captured and moved continuously changing data from financial source systems into a data warehouse, automatically configuring the analytic environment as the source systems changed.

The company raised a $5M Series B round from Battery Ventures in 2004 and was named one of the 50 fastest-growing private companies in Silicon Valley that year. In December 2005 it was acquired by NCR's Teradata data warehousing division, which folded the FPM and data warehousing technology into the Teradata enterprise data warehouse offering.

**Status:** Acquired (Teradata / NCR, December 2005). No live website, developer portal, documentation, or public API surface. This profile is retained as a historical portfolio-lead record rather than an active API provider.
